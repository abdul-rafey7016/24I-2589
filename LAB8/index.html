Step 5: Code Explanations

  1. Which line decides how tall each bar is?
    .attr("height", d => innerHeight - yScale(d[1])) calculates the height of each rectangle by taking the vertical distance from the scaled data value down to the bottom margin.
  2. What would happen if I changed .range([innerHeight, 0]) to .range([0, innerHeight])?
    The vertical Y-axis orientation would invert, causing the scale to draw top-down and making the bars grow downwards from the top margin instead of upwards from the bottom.
  3. How many <rect> elements are in the page, and why?
    There are 3 <rect> elements on the page because D3 creates exactly one SVG rectangle shape for each aggregated group in the dataset (3 penguin species or 3 islands).
